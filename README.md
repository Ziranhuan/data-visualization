# 数据可视化作业集 - Data Visualization Assignments

## 📊 项目概述

本项目是数据可视化课程的完整作业集合，从Python基础和matplotlib入门开始，逐步深入到高级数据可视化技巧。使用**Pandas**、**Matplotlib**、**Seaborn**等Python库进行多维度的数据分析和专业级可视化实践。

通过7个阶段的学习，掌握从基础绘图到高级交互式可视化的完整技能体系。

## 🎯 学习目标

本课程作业集旨在培养以下能力：

1. **Python数据科学基础** - 掌握Pandas、NumPy等数据处理库
2. **可视化核心技能** - Matplotlib、Seaborn、Plotly等绘图库
3. **图表选择原则** - 根据数据特性选择合适的可视化方案
4. **数据预处理与特征工程** - 真实数据的清洗与转换
5. **高级可视化技巧** - 双轴图、分面网格、自定义美化等
6. **数据驱动决策** - 通过可视化分析发现隐藏规律

## 📚 关键技术点

### 核心库函数对比

| 功能 | Matplotlib | Seaborn |
|------|-----------|---------|
| 基础绘图 | ✅ 基础简洁 | ✅✅ 默认优美 |
| 统计估计 | ❌ 不内置 | ✅✅ 自动计算 |
| 多图布局 | ✅ subplots | ✅✅ FacetGrid |
| 美化定制 | ✅ 繁琐 | ✅✅ 简洁 |
| 底层控制 | ✅✅✅ 完全 | ✅ 有限 |
