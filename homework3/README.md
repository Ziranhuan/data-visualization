## 💡 核心要点

1. **Seaborn相比Matplotlib的优势**
   - 更美观的默认样式
   - 内置统计估计功能
   - 更易于实现复杂可视化

2. **主要函数族**
   - 关系探索：scatterplot, lineplot, regplot
   - 分类比较：barplot, boxplot, violinplot
   - 分布展示：histplot, kdeplot, jointplot
   - 相关分析：heatmap, clustermap, pairplot
