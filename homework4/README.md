## 🛠️ 核心技术

### 图表类型
- **双轴图表** - 展示相关但量纲不同的数据
- **分面网格** - 多条件下的平行比较
- **堆叠图** - 部分与整体的关系展示
- **等值线图** - 二维密度分布
